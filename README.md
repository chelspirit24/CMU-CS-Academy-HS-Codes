# CMU High School Codes 

For three years, I took programming courses in high school. We used CMU CS Academy to learn Python coding that produced visuals from the CMU Graphics package. 

Here is a collection of some of the interactive graphics, animations, and games I created during that time. 

## Projects

### Modern Kitchen (`kitchen.py`)
A visual scene of a modern kitchen created using CMU Graphics primitives. It features detailed cabinets, an island with chairs, and hanging lights. It demonstrates the use of coordinate geometry, color manipulation, `for` loops, and grouping shapes.

### Pigs Jump Game (`pigs-jump.py`)
An interactive hurdle jumping game! 
- **Controls**: Hold the `Right Arrow` key to move forward, and press `Spacebar` to jump over the hurdles. If you hit a hurdle, press `r` to reset the game.

### Follow the Mouse Pigs (`pigs.py`)
An interactive animation where three pigs walk across a sunny field.
- **Controls**: Move your mouse across the screen and watch the pigs follow your movement!

### RuPaul's Drag Race Soundboard (`rupaul-soundboard.py`)
A fun, interactive soundboard featuring iconic soundbites and quotes from RuPaul's Drag Race.
- Includes 9 clickable buttons that produces notable sound effects and quotes from RuPaul's Drag Race.

## Note
To run any of these projects, the `cmu_graphics` package must be installed
